# Selling TermFX — quick runbook

Everything is built and ready to upload. The only remaining step needs a human
(you): creating a merchant account, because payment processors require your
legal identity and tax details. That's ~10 minutes, free, once.

## What's already done

- `products/packed/` — the sellable artifacts (single-file executables +
  a bonus WAV), generated by `python3 termfx.py products`.
- `products/manifest.json` — the catalog: id, title, blurb, price, file.
  Prices are final here. Edit manifest/`META` to change; rebuild.
- `LICENSE.md` — the buyer license shown with each product.
- Prices: $6.99 (Ars Subtilior) · $3.99 (Maria, Sinai, David) ·
  $2.99 (Sophia, Deseret, Light) · $0 (Starfield teaser).

## Set up a store (pick one)

### Option A — Lemon Squeezy (recommended)
Handles EU VAT, PayPal + cards, worldwide. No monthly fee (commission only).
1. lemonqueezy.com → "Getting started" → create account + Stripe/PayPal connect.
2. Products → New. For each manifest item, upload the file,
   set price from manifest, paste the blurb + license notes.
3. Publish. Share the product links.

### Option B — Gumroad
Simplest. gumroad.com → sign in with an email → Products → New → upload file,
set price, paste blurb. Each product gets a link on your own profile page.

### Option C — itch.io
Niche-fun for terminal art: itch.io → Upload new project → kind: "Other" →
upload file, set price ($2+ enables "Pay What You Want" for the teaser).
Good landing page aesthetics and a community that enjoys this genre.

## After the store is live

Ship a `--changelog` / update channel by regenerating with
`python3 termfx.py products` and re-uploading on new versions. Keep `CLAIM.md`
current so the always-on agent never overlaps your store work.
